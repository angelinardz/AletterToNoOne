# ALetterToNoOne 💌

A minimalist web app that lets you write a letter to no one — and watch it disappear.

Built as a safe space for emotional release: no accounts, no saving, no sending. Just you and the words you need to get out.

---

## What it does

- Gives you a distraction-free space to write freely
- Deletes your letter automatically after a set time
- Uses dynamic prompts to guide reflection without pressure
- Designed with a **privacy-first** approach — nothing is stored or transmitted

---

## Why I built it

I made this during Girls Who Code because I wanted to explore how technology could support emotional well-being without creating a social footprint. The anonymity is the point — sometimes you just need to say something without consequence.

## Features

- 🔒 **No backend** — nothing leaves your browser
- 📱 **Responsive design** — works on any screen size

## How to run it locally

```bash
git clone https://github.com/angelinardz/AletterToNoOne.git
cd AletterToNoOne
open html/index.html
```

No dependencies, no build step. Just open in a browser.
